# СетьРезерв

Рабочее пространство для проектирования IoT-сетей с первой расчётной моделью буфера шлюза. Визуальная основа — семь исходных макетов в `dedign/` (название папки сохранено).

## Запуск

Требуется Node.js 22.12+ (проверено на 24.15).

```sh
npm install
npm run dev
```

Откройте http://127.0.0.1:5173. Для production-сборки: `npm run build`, для локального просмотра сборки: `npm run preview`. Навигация использует HashRouter: адреса вида `/#/editor` обновляются без 404 на статическом хостинге. При размещении в подпапке используются относительные пути к ресурсам. Старые адреса без `#` нужно заменить новыми; перехватить 404 до загрузки приложения может только сам сервер.

## Возможности

- Проекты: создание из трёх шаблонов, поиск, переименование, избранное, архив и восстановление.
- Редактор React Flow: добавление, перемещение, соединение и удаление устройств; параметры выбранного узла и источников телеметрии. Удаление выбранного узла или линии — Delete/Backspace. Узлы соединяются перетаскиванием между точками на краях.
- Воспроизведение: подготовка → работа сети → события → завершение. Узлы и линии подсвечиваются по событиям; есть пауза, ускорение ×2 и отмена. При скрытии вкладки включается пауза. В историю записывается только завершённый запуск; снимок проекта фиксируется в начале.
- Сценарии: несколько событий, объект, время начала, длительность, рост нагрузки, равномерная или одновременная отправка, три дополнительных размера буфера. Расчёт поддерживает отказ канала и принимающего сервера. Сохранение по кнопке; переключение сценария сохраняет текущий корректный сценарий.
- Результаты: расчёт FIFO-очереди, потерь, задержек (средняя и p95), очистки, недоставленных остатков; сравнение буферов и история снимков. Расчёт выполняется в Web Worker.
- Отчёты: снимок конфигурации, сценария, версии модели и рассчитанных показателей. Кнопка «Печать / PDF» открывает диалог браузера; выберите «Сохранить как PDF».
- Профиль: локальное редактирование имени, почты, специализации, описания и уведомления о готовности результата.
- Адаптивная вёрстка, клавиатурный фокус, модальные формы, состояния пустых списков.

## Границы расчётной модели

Модель `queue-1.1` рассчитывает одну цепочку: группы датчиков → основной шлюз → канал → сервер. Скорость цепочки — минимум скоростей трёх звеньев; буфер включает передаваемое сообщение, при переполнении отвергаются новые сообщения. Размер сообщения и протоколы не моделируются. Резервирование и отказ шлюза пока не рассчитываются: неподдерживаемые настройки отклоняются. В старых сохранённых сценариях нужно выключить резерв перед запуском. До 500 000 сообщений и 3600 секунд на расчёт. Backend и авторизации нет.

Подробная методика, единицы, аналитические проверки и границы модели: [спецификация](docs/СетьРезерв_расчётная_модель_v03.md). Сопоставление с физическим стендом и независимым симулятором ещё предстоит. Старые запуски без расчётных данных отмечены как архивные демонстрационные; новые расчёты не подменяют историю.

Данные хранятся в localStorage под ключом `setreserve-workspace-v1`. Проекты и схемы сохраняются автоматически; сценарии и профиль сохраняются по кнопке. Очистка данных сайта сбросит рабочее пространство. Изменение проекта не изменяет старые запуски или отчёты: они используют снимки.

## Структура

- `src/data/model.ts`: типы, шаблоны, подготовленные результаты, валидация и снимки запусков.
- `src/data/simulation.ts`: расчёт, проверка поддерживаемой топологии и определения метрик.
- `src/data/calculation.worker.ts`: выполнение расчёта вне главного потока интерфейса.
- `src/data/store.ts`: Zustand, действия и адаптер localStorage; место будущего подключения API.
- `src/components/`: общие элементы, предпросмотр схемы и график.
- `src/pages/`: проекты, редактор и параметры, сценарии, результаты, отчёты, профиль.
- `src/styles/`: CSS-переменные и SCSS Modules, адаптивные и печатные стили.

Стек: React, TypeScript, Vite, React Router, Zustand persist, @xyflow/react, Recharts, SCSS Modules, Lucide.

## Проверка

```sh
npm test
npm run build
```

Тесты проверяют аналитические примеры, синхронные всплески, отказы и нагрузку, баланс сообщений, задержки, границы модели, неизменность снимков и воспроизведение.

Ручной маршрут: создать проект → соединить/переместить узлы → настроить и сохранить событие → запустить сценарий → создать отчёт → печать/PDF → перезагрузить страницу и проверить сохранение.

Документация использованных механизмов: [React Flow](https://reactflow.dev/learn/concepts/adding-interactivity), [Zustand persist](https://zustand.docs.pmnd.rs/reference/integrations/persisting-store-data).

Браузерные тесты используют установленный Google Chrome и отдельный локальный сервер без SPA fallback (порт 4174). Проверяются обновление всех разделов в корне и подпапке, пауза, отмена, сохранение завершённого запуска, отчёты и мобильное окно воспроизведения. Перед запуском `npm run test:e2e` выполните `npm run build`.


## Обновление интерфейса — 7 ноября 2026

Главная получила анимированную сеть, возврат к последнему проекту и встроенную насосную станцию: 11 узлов, 700 датчиков, 130 сообщений/с. Это заданный инженерный пример; параметры доступны для изменения. Повторное открытие примера использует существующий проект.

Редактор показывает входящий поток, скорость цепочки и проверку топологии; холст можно развернуть. События перемещаются по временной шкале. Воспроизведение показывает рассчитанные очередь, доставки и потери с перемоткой, паузой и скоростями ×1/×2/×4. Числа относятся к последнему рассчитанному срезу, его время подписано; график хранит 301 срез. Большие схемы при показе автоматически компонуются, исходные позиции сохраняются.

Результаты содержат ключевые показатели, переключаемые линии графика, помощника с шаблонными объяснениями на данных запуска и повторное воспроизведение. В отчёт добавлен график. Three.js и внешняя AI-служба не подключались. Границы расчётной топологии прежние: одна основная цепочка, без расчётного резервирования.

Проверено: production-сборка, 30 модульных тестов, 5 браузерных сценариев. Временная трасса проверяется на баланс сообщений и совпадение итогов с результатом. Старые снимки остаются совместимыми; отсутствующие в них временные счётчики показаны прочерками.
